# v3 matcher: synthetic component test

**Component test (synthetic geometry, not rendered images).** It tests only the association step on generated geometry; it is not evidence about real photos or real-model accuracy. Related: [[HANDOFF]], [[DECISIONS]].

This page is generated by `scripts/render_synth_component_doc.py` from `results/synth_component_rows.csv`, `results/synth_component.json` and `results/synth_component_tuning.csv`. Run: `scripts/eval_synth_component.py --stage tune` then `--stage test` (CPU, v3 inference on CPU).

- Data: `data/dag_v3_capped` (100 val episodes used for tuning, 100 held-out test episodes; mean true count 32.3). v3: `runs/match_v3_capped/best.pt`, unchanged.
- v1, v2 and sync were tuned on the validation split only (grids in `results/synth_component_tuning.csv`), frozen, then run once on test. "default" rows are the untuned settings from the first comparison.
- Depth variants: `nan_depth` (NaN depth, the v2/sync visibility check never rejects) and `finite_depth` (z-buffered depth with multiplicative noise, occlusion check active). v1 and v3 do not read depth, so their rows are identical in both.
- Intervals: 2,000-sample bootstrap over the test episodes, mean [95% CI].
- Zero-count scenes in the test split: 0, so the zero-scene false count is not measurable here.
- Injected false-positive detections per episode: 17.8 on average.

## Reading

- Once tuned on validation, v1 has the lowest count MAE on this test split and beats v3 (paired difference above). The earlier "v3 beats v1/v2/sync" result held only against untuned defaults. v3 keeps most of its false-positive detections (about 17 per episode injected), which is where its count error comes from.
- Tuned v2 and sync have the lower MAE but a lower association F1 than their defaults: they trade F1 for a count that lands closer, by dropping detections (missed and no false positives). F1 and count error disagree, so count is the headline.
- v3+sync is the best of the v3 arms on count MAE but is still behind tuned v1.
- One synthetic generator, one seed of v3; tuned thresholds were chosen on 100 validation episodes from the same generator, so tuned numbers are likely optimistic for new data.
